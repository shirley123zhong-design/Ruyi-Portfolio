# breif for how to run the folder

## Setup

1. Create and activate a virtual environment

2. Install dependencies in the virtual environment
```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```
3. run the main file
python main.py
Open your browser to:
http://127.0.0.1:8050/ (or http://localhost:8050/)

4. Run individual analysis file
python -m analysis.analysis_rq1


Open your browser to:
http://127.0.0.1:8050/ (or http://localhost:8050/)

## Notes
- Stop the server with Ctrl+C.
- Keep dependencies to libraries updated in the requirements.txt file
